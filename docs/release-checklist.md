# v0.4.0-rc.1 发行前测试

状态：**2026-10-22 用户反馈测试通过并授权发布，v0.4.0-rc.1 已公开发行。**

下列项目作为复现与后续版本验收清单，不表示每项都有独立的自动化结果。

## 开始

1. 将候选 ZIP 完整解压到一个新文件夹，不要覆盖旧目录或复制旧的 `data/`。
2. 确认原服务已停止，双击解压目录中的 `启动软件.cmd`。首次启动需要 Python 3.11+ 和联网安装依赖；候选包已包含前端构建文件。
3. 初次打开应为空白工作空间；不应出现旧订阅、旧标题、旧令牌或自动开启 LAN 共享。
4. 浏览器偏好按同一站点地址共用。需要验证完全首次使用效果时，清除此站点的网站数据或使用隐私窗口。

## 功能

- [ ] 载入演示配置，显示 4 个节点、3 个组，可预览 YAML。
- [ ] 节点改名/排除、代理组改名/成员调整、规则新增/排序后能保存，重载后保留。
- [ ] 未保存的草稿不影响订阅输出；保存后客户端更新得到修改。
- [ ] 使用你自己的 Clash/Mihomo 订阅导入、刷新，刷新后编辑记录仍生效。
- [ ] AI 分流清单包含 Muse AI，出口可选，重复应用不重复新增，停用后恢复普通规则。
- [ ] 右上角配色：五套预设、颜色选择器、十六进制输入、重载恢复、默认恢复可用。
- [ ] 本机复制订阅、下载 YAML、历史恢复、停用和重新生成链接可用。
- [ ] 开启局域网共享后，同网设备可导入；共享端口访问 `/api/subscriptions` 返回 404。
- [ ] 关闭局域网共享后，该端口停止提供订阅；端口冲突时有提示并保留原可用设置。
- [ ] 停止并重启服务后设置恢复；`停止服务.cmd` 能关闭管理服务及共享端口。
- [ ] 窄窗口下可导航、编辑和关闭弹窗。
