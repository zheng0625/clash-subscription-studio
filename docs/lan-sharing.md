# 局域网订阅共享 v0.3.0

## 使用

1. 在本机打开工作台，进入任一订阅的“设置”。
2. 在“局域网订阅共享”勾选启用，选择本机内网地址与共享端口（默认 8767），点击“保存共享设置”。此设置供所有订阅共用。
3. 右侧订阅卡片切换到“局域网”，点击“复制局域网订阅”。设置页也提供完整链接。
4. 在同一网络的手机、电脑或路由器的 Clash/Mihomo 客户端中新增远程订阅，粘贴该链接。
5. 保存并发布配置后，其他设备更新订阅即可获取新版 YAML。手机不需要安装这个编辑器。

地址形式为 `http://电脑内网IP:8767/sub/随机令牌`。本机原有 `127.0.0.1:8765/sub/...` 链接继续可用。每份订阅的本机地址和局域网地址使用相同令牌和同一份已发布 YAML，重置令牌或停用订阅会同时影响两种地址。

## 运行与设置

- 管理界面与编辑 API：固定绑定 `127.0.0.1:管理端口`，默认 8765。
- 局域网订阅：独立 IPv4 监听器，默认 8767；共享关闭时不监听该端口。
- 共享设置保存于 `data/network.json`，重启时恢复；数据目录仍是本机 `data/`。
- 共享端口不能与管理端口相同；端口被占用时保留原来可用的监听器及设置。
- 自动检测当前内网地址。电脑网卡、Wi-Fi 或 DHCP 地址改变后，点击“刷新网卡地址”，重新复制链接。
- 电脑关机、休眠、停止软件或停用共享后，其他设备无法更新；已经下载的配置由各客户端保存。

同一个订阅导出的全局配置字段（端口、DNS、TUN 等）与本机版本一致；不同设备对这些字段的处理和内核兼容性由其客户端决定。

## 访问范围

共享监听器仅注册 GET / HEAD `/sub/{token}`，没有管理界面、订阅列表、编辑 API、网络设置 API 或接口文档。请求来源仅允许 RFC1918 私有 IPv4（10/8、172.16/12、192.168/16）和回环地址。请求 Host 仅允许本机检测到的内网 IPv4 或回环域名。代理转发头不参与来源判断。

链接中的令牌赋予读取该配置的权限，配置内可能含节点凭据；请在可信局域网内传递。当前提供 HTTP 局域网分发，未提供公网托管或 HTTPS。不要在路由器上做公网端口映射。

## 无法连接时

1. 确认手机连接的是同一局域网 Wi-Fi，使用的是“局域网”链接，地址不是手机自身的 `127.0.0.1`。
2. 确认设置显示“运行中”，本机程序仍在运行，电脑未休眠。
3. 确认地址属于当前网卡，检查访客 Wi-Fi、AP 隔离、VLAN 或设备之间的访问限制。
4. Windows 防火墙开启时，可双击根目录的 `配置局域网防火墙.cmd`。脚本会申请管理员权限，仅放行当前共享 TCP 端口，限定 Private（专用）网络和 LocalSubnet（本地子网）。不修改系统防火墙整体开关。
5. 自定义端口后，若防火墙开启，请重新运行该脚本。撤销本软件创建的规则可运行：

```powershell
.\configure-lan-firewall.ps1 -Remove
```

脚本只管理本工作目录对应的 Clash Studio 规则，不更改其他应用的规则。若当前网络是 Public（公用），该 Private 规则不会在该网络生效。

## 验证范围

自动检查包括：只读路由隔离、令牌失效与停用、公共来源拒绝、Host 检查、转发头伪造拒绝、真实 HTTP 监听启停、换端口、端口冲突回退和设置重启恢复。真实手机或其他物理设备能否连入，还需在现场网络测试。
